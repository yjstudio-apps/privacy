개인정보처리방침 — 구독끝 (SubEnd)

시행일 및 최종 수정일: 2026년 9월 30일

YJ Studio가 제공하는 「구독끝 — 결제일·무료체험 종료 알리미」(영문 이름: SubEnd, Android 패키지: com.subscriptionend.reminder, 이하 “앱”)의 개인정보 처리에 대해 안내합니다. 앱에는 회원가입, 계좌 연결, 개발자 서버를 통한 구독 정보 동기화 기능이 없습니다.

1. 기기에 저장하는 정보와 이용 목적

사용자가 입력한 구독 이름, 금액·통화, 카테고리, 결제일·종료일·해지 권장일, 이용 상태, 메모, 결제수단 별칭, 해지 페이지 주소 및 알림 설정을 기기 내부에 저장합니다. 언어·테마·기본 통화 등 앱 설정도 기기에 저장합니다.

이 정보는 구독 목록, 결제 일정, 지출 요약, 로컬 알림 및 사용자가 요청한 백업·복원 기능을 제공하는 데 사용합니다. 앱은 구독 정보와 메모를 개발자 서버나 광고 SDK로 보내지 않습니다. 실제 카드 번호, 은행 계좌 또는 금융기관 로그인 정보를 입력받거나 계좌에 접속하지 않습니다.

2. Google AdMob 광고와 외부 서비스

앱은 Google AdMob을 이용해 배너·전면·앱 시작 광고를 표시합니다. 광고 SDK는 광고 제공, 광고 성과 분석, 서비스 진단 및 부정 사용 방지를 위해 아래 정보를 수집하거나 공유할 수 있습니다. 실제 처리 범위는 기기, 지역, 광고 설정 및 Google의 정책에 따라 달라질 수 있습니다.

앱은 GPS 등 정밀 위치 권한, 연락처·문자·이메일·통화 기록을 읽는 권한을 요청하지 않습니다. 위치 권한을 사용하지 않더라도 광고 서비스가 IP 주소로 대략적인 위치를 추정할 수 있습니다. Google의 광고 서비스 데이터는 Google 정책에 따라 해외에서 처리될 수 있으며, 보관 및 삭제 기준도 Google의 정책을 따릅니다.

  • Google 개인정보처리방침
  • Google 광고 및 개인정보 보호 안내
  • Google Mobile Ads SDK 데이터 처리 안내

사용자가 해지 페이지를 열면 외부 브라우저와 해당 웹사이트의 정책이 적용됩니다. 백업 파일을 공유하면 사용자가 선택한 앱 또는 저장 서비스에 파일이 전달될 수 있으며, 그 서비스의 정책이 적용됩니다.

3. 광고 개인정보 선택

Android 기기 설정에서 제공하는 광고 개인정보 보호 기능을 통해 광고 식별자를 재설정하거나 삭제하는 등 광고 관련 선택을 할 수 있습니다. 제공되는 메뉴는 Android 버전과 기기에 따라 다릅니다. 광고 식별자를 삭제하더라도 IP 주소나 진단 정보 등 모든 광고 관련 처리가 중단되는 것은 아닙니다.

현재 앱에는 별도의 광고 개인정보 선택 또는 동의 재설정 화면이 제공되지 않습니다. 개인정보 처리에 대한 문의나 적용 가능한 권리에 관한 요청은 아래 연락처로 보내 주세요. Google이 처리하는 데이터와 관련한 선택은 Google의 개인정보 보호 안내도 확인해 주세요.

4. 권한과 알림

  • 알림: 결제일·무료체험 종료일·해지 권장일 등을 알려 주는 로컬 알림에 사용합니다. 알림 권한을 거부해도 구독 관리 기능은 사용할 수 있습니다.
  • 파일 선택·공유: 사용자가 백업 가져오기 또는 내보내기를 실행할 때 선택한 파일을 읽거나 백업 파일을 생성·공유합니다.
  • 네트워크: 광고 제공 및 사용자가 선택한 외부 웹페이지 접근에 사용합니다.

예약된 알림은 기기에서 처리합니다. 기기 잠금 화면 설정에 따라 구독 이름·금액·일정이 알림에 표시될 수 있으므로, 필요하면 시스템 알림 설정에서 미리보기를 숨길 수 있습니다.

5. 기기 백업과 데이터 보관

구독 정보는 사용자가 삭제할 때까지 기기에 보관합니다. 사용자가 직접 만든 JSON 백업에는 구독 이름·메모·결제수단 별칭 등 입력 정보가 포함되며, 별도로 암호화하지 않습니다. 백업 파일은 안전한 위치에 보관해 주세요.

기기 및 운영체제의 백업·복원 설정에 따라 앱 데이터가 시스템 클라우드 백업이나 기기 간 이전에 포함될 수 있습니다. 이 처리는 개발자 서버 동기화와 별개이며, 운영체제 또는 백업 제공자의 정책을 따릅니다. 개발자는 이 백업에 접근할 수 없습니다.

6. 삭제 방법과 이용자의 권리

  • 구독 하나 삭제: 홈에서 카드를 왼쪽으로 밀거나 해당 구독의 상세 화면에서 삭제합니다.
  • 전체 구독 삭제: 설정 → 전체 데이터 삭제에서 확인 문구를 입력하면 저장된 구독과 예약 알림을 삭제합니다.
  • 앱 삭제: 앱을 제거하면 기기에 저장된 앱 데이터가 삭제됩니다. 기존 시스템 백업은 남아 있거나 재설치 시 복원될 수 있습니다.
  • 백업 삭제: 내보낸 파일이나 시스템·클라우드 백업은 사용자가 해당 저장 위치 또는 백업 서비스에서 별도로 삭제해야 합니다.

앱의 데이터 삭제 기능은 Google이 별도로 처리하는 광고 데이터를 삭제하거나, Google에 삭제 요청을 보내는 기능이 아닙니다. 개발자는 로컬 구독 데이터에 원격으로 접근할 수 없으므로 앱에서 직접 수정·삭제할 수 있습니다. 적용되는 법령에 따른 열람·정정·삭제·처리 제한 등의 요청은 아래 연락처로 문의할 수 있으며, Google이 처리하는 정보는 Google의 관련 요청 절차도 이용할 수 있습니다.

7. 문의 정보와 아동의 개인정보

이메일로 문의하면 문의자가 제공한 이메일 주소와 문의 내용을 답변 및 후속 대응에 필요한 기간 동안 처리합니다. 불필요한 카드 번호, 계좌 정보 또는 민감한 정보는 보내지 마세요. 문의 처리 목적이 달성되면 불필요한 문의 정보를 삭제하며, 법령상 보관 의무가 있는 경우 해당 기간을 따릅니다.

앱은 아동을 대상으로 설계되지 않았으며, 만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 관련 우려가 있으면 아래 연락처로 문의해 주세요.

8. 변경 안내와 연락처

기능 또는 개인정보 처리 방식이 바뀌면 이 페이지의 내용과 최종 수정일을 갱신합니다. 필요한 경우 앱 업데이트나 앱 내 안내를 통해 변경 사항을 알립니다.
