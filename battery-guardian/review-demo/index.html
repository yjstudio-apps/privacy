Battery Guardian: user-started charging monitoring

This is an Android 16 emulator recording of the app's debug build. Android's test commands supply simulated battery readings (79% → 80% → 85% and unplug). It demonstrates the real foreground service and notification flow; it is not a physical charger or battery performance test. No camera footage or personal user data is included.

Open MP4 video directly

  1. The user explicitly enables the current charging session in the visible app.
  2. An ongoing notification identifies monitoring and provides a Stop action.
  3. The screen turns off. Android test battery events reach the target.
  4. On wake, the notification shows that the 80% target was reached.
  5. An unplug event ends monitoring automatically. The final app view shows monitoring disabled.

Why a foreground service is used

The app's core function is a timely alert at the user's charging target while the screen is off. Deferring or pausing monitoring can miss the threshold. The service receives Android battery broadcasts without polling, a wake lock or exact alarms. The user can stop it in the app or ongoing notification; unplug ends it. The app does not start monitoring automatically at boot or bypass force-stop.
