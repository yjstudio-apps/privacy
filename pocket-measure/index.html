개인정보처리방침 — Pocket Measure

2026-10-04

YJ Studio가 제공하는 Pocket Measure (Android 패키지: com.yjlab.pocketmeasure)의 개인정보 처리를 안내합니다.

1. 측정 정보와 기기 내 저장

자 눈금과 단위 변환은 기기에서 계산합니다. 기울기 센서 값은 수평계·각도계 작동 중 메모리에서 처리하며 측정 이력을 저장하지 않습니다. 자 보정 배율, 센서 영점, 허용 오차와 알림 방식, 테마, 즐겨찾는 도구와 마지막 사용 도구를 DataStore에 저장합니다. 변환 입력값은 화면 상태로만 처리하며 앱에 기록으로 저장하지 않습니다. 자체 서버, 로그인 또는 개발자 서버 동기화 기능이 없습니다.

2. 광고와 외부 서비스

앱은 Google Mobile Ads(AdMob) 및 User Messaging Platform을 사용합니다. 배포용 빌드는 앱별 운영 광고 식별자를 사용하고 개발용 빌드는 Google 테스트 광고 식별자를 사용합니다. 실제 광고 제공 여부는 Google의 앱 검토와 광고 재고 등에 따라 달라집니다. 동의 상태상 광고 요청이 허용될 때에만 광고 SDK를 초기화하고 요청합니다. 필요한 동의 설정을 확인하지 못하면 광고 영역은 비어 있을 수 있습니다.

광고 제공·측정, 분석과 부정 사용 방지를 위해 SDK는 기기·광고 및 앱 세트 식별자, IP 주소로 추정한 대략적인 위치, 앱·광고 상호작용, 진단·성능 정보를 수집·공유할 수 있습니다. SDK 통신은 전송 중 암호화되며 국외 처리가 이루어질 수 있습니다. 제공자의 보관·삭제 기준은 Google 정책에 따릅니다. 앱의 측정값, 변환 입력, 오류코드 검색어, 가전 이름·모델명은 광고 요청에 포함하지 않습니다.

Google이 요구할 때 설정의 ‘광고 개인정보 설정’에서 선택을 변경할 수 있습니다. Android의 광고 개인정보 보호 설정에서도 광고 ID를 재설정하거나 삭제할 수 있지만 모든 네트워크·진단 처리가 중단되는 것은 아닙니다.

  • Google 개인정보처리방침
  • Google 광고 개인정보 안내
  • Mobile Ads SDK 데이터 공개 안내

3. 권한

인터넷·네트워크 상태와 광고 ID는 광고·동의 SDK에 사용합니다. 진동은 사용자가 선택한 수평 도달 피드백에 사용합니다. 기울기 센서는 측정 화면이 활성화된 동안 사용합니다. 카메라, 마이크, 연락처, 정밀 위치 또는 전체 저장공간 권한은 요청하지 않습니다. 카드 보정에 카드 번호나 사진을 사용하지 않습니다.

4. 저장 정보 초기화

설정의 ‘설정 및 보정 초기화’에서 보정, 영점, 즐겨찾기 및 설정을 지울 수 있습니다. 측정값은 검증된 전문 측정 도구를 대체하지 않습니다.

5. 보관·보호와 삭제

저장 정보는 앱 전용 기기 저장 영역에 사용자가 삭제할 때까지 보관합니다. 별도 앱 암호화 기능은 제공하지 않으므로 기기 잠금 등 Android 보호 기능을 이용하세요. 앱 데이터는 Android 자동 백업과 자동 기기 이전에서 제외하도록 설정했습니다. 운영체제·제조사 기능에는 해당 제공자의 정책이 적용됩니다.

Android ‘설정 → 앱 → 해당 앱 → 저장공간 → 데이터 삭제’ 또는 앱 제거로 로컬 정보를 삭제할 수 있습니다. 앱 안에서의 삭제 방법은 아래 기능 설명을 확인하세요. 로컬 삭제는 Google 광고 데이터나 이미 공유한 내용을 삭제하지 않습니다. 개발자는 기기 내 정보에 원격으로 접근할 수 없습니다. 이용자는 기기에서 정보를 수정·삭제할 수 있으며 적용 법령에 따른 권리 요청은 아래 이메일로 문의할 수 있습니다.

6. 문의·외부 링크·아동

문의 메일을 직접 보내면 이메일 주소와 문의 내용을 답변 및 후속 대응에 필요한 기간 동안 처리합니다. 목적이 달성되면 불필요한 정보를 삭제하고 법령상 보관 의무가 있으면 해당 기간을 따릅니다. 실제 카드 번호, 비밀번호 등 민감한 정보는 보내지 마세요.

공식 출처, 정책 또는 이메일 앱을 열면 해당 외부 서비스의 정책이 적용됩니다. 이 정책 웹사이트 방문 정보는 GitHub 개인정보처리방침에 따라 처리될 수 있습니다. 앱은 만 14세 미만 아동을 대상으로 설계되지 않았으며 계정 가입을 요구하지 않습니다.

7. 변경 안내와 연락처

기능과 처리 방식이 달라지면 이 페이지와 수정일을 갱신하고 필요한 경우 앱에서도 안내합니다.
