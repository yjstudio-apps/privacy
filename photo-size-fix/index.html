개인정보처리방침 — Photo Size Fix

시행일 및 최종 수정일: 2026년 10월 4일

YJ Studio(스토어 개발자명: YJ Lab)가 제공하는 「Photo Size Fix」(Android 패키지: com.yjlab.photosizefix, 이하 “앱”)의 개인정보 처리에 대해 안내합니다. 앱은 회원가입, 로그인, 개발자 서버 또는 Firebase를 사용하지 않습니다.

1. 선택한 사진과 압축 작업

선택한 사진은 서버로 전송되지 않으며 모든 압축 작업은 사용자의 기기에서 처리됩니다. Android 사진 선택기를 통해 사용자가 선택한 사진만 읽어 파일명, 용량, 해상도, 형식과 EXIF 방향을 확인하고, 목표 KB·MB 이하의 JPG 또는 WebP 결과를 만듭니다. 원본 사진을 수정하거나 앱 내부에 따로 복사하지 않으며, 원본에 대한 장기 접근 권한을 저장하지 않습니다.

Android 사진 선택기는 기기 설정에 따라 클라우드 사진 제공자의 사진도 표시할 수 있습니다. 해당 사진을 기기로 가져오는 과정은 운영체제와 제공자의 정책을 따릅니다. 앱이 압축을 위해 사진을 외부로 업로드하는 것은 아닙니다.

2. 기기에 보관하는 정보

출력 형식, 메타데이터 처리와 화면 테마 등의 설정, 최근 압축 기록(원본 파일명, 원본·결과 용량, 처리 시각)은 앱 전용 저장 영역에 보관합니다. 최근 기록은 최대 50건이며 원본 사진이나 원본 접근 주소를 기록에 저장하지 않습니다. 이 정보는 설정 유지와 최근 작업 표시를 위해 사용하며 개발자에게 전송하지 않습니다.

압축 결과는 저장·비교·공유를 위해 앱 내부에 임시 보관합니다. 생성 후 7일이 지난 결과 파일은 다음 앱 실행 시 정리합니다. 따라서 앱을 실행하지 않는 동안에는 즉시 삭제되지 않을 수 있습니다. 갤러리에 저장하거나 다른 앱에 공유한 파일은 이 정리 대상에 포함되지 않습니다.

3. EXIF와 사진의 위치정보

기본 설정은 GPS 위치정보 제거입니다. 사용자는 모든 EXIF 제거 또는 지원하는 EXIF 유지로 바꿀 수 있습니다. EXIF 유지를 선택하면 원본에 포함된 촬영 위치, 촬영 시각, 카메라 정보 등이 결과 파일에 남을 수 있습니다. 내장 썸네일과 제조사 전용 메타데이터는 복사하지 않습니다.

앱은 기기의 현재 위치를 조회하지 않습니다. 사진에 이미 포함된 위치정보와 기기의 위치 권한은 별개입니다. 결과를 외부에 공유하기 전에 메타데이터 설정을 확인해 주세요.

4. Google AdMob 광고와 외부 서비스

앱은 Google AdMob의 배너·네이티브 광고를 사용하며 선택적 보상형 광고를 지원하는 구조를 포함합니다. 비공개 테스트 버전은 Google 테스트 광고를 사용합니다. 광고 SDK는 광고, 분석과 부정 사용 방지를 위해 대략적인 위치를 추정할 수 있는 IP 주소, 앱·광고 상호작용, 진단·성능 정보, 앱 세트 ID 등 기기·계정 관련 식별자를 수집하거나 공유할 수 있습니다. 이 앱은 Android 광고 ID 권한을 요청하지 않습니다.

광고 데이터는 전송 중 TLS로 암호화되며 Google의 정책에 따라 처리·보관됩니다. 처리 지역은 국외를 포함할 수 있습니다. 앱은 사진, 사진 URI, 파일명, EXIF 또는 최근 압축 기록을 광고 SDK에 전달하지 않습니다. 광고 연결이 없어도 사진 압축과 저장을 사용할 수 있습니다.

  • Google 개인정보처리방침
  • Google 광고 및 개인정보 보호 안내
  • Google Mobile Ads SDK 데이터 처리 안내

이 방침 등 외부 링크를 열면 브라우저와 해당 사이트의 정책이 적용됩니다. 방침을 제공하는 GitHub Pages의 방문 정보는 GitHub 개인정보처리방침에 따라 처리될 수 있습니다.

5. 광고 개인정보 선택

광고 동의가 필요한 지역·설정에서는 Google User Messaging Platform을 통해 동의 안내를 제공합니다. Google이 개인정보 선택 화면을 요구하면 앱 설정의 ‘광고 개인정보 설정’에서 선택을 다시 열 수 있습니다. 해당 메뉴는 필요한 경우 표시됩니다. 테스트 광고용 앱 ID에서는 실제 게시자 동의 메시지가 제공되지 않을 수 있습니다.

Google이 처리하는 정보에 관한 선택과 요청은 Google의 개인정보 보호 안내도 확인해 주세요. 앱의 최근 기록 삭제는 광고 서비스 데이터의 삭제 요청이 아닙니다.

6. 갤러리 저장과 공유

‘저장’을 실행하면 결과 사진을 갤러리의 Pictures/Photo Size Fix에 저장합니다. ‘공유’를 실행하면 사용자가 선택한 다른 앱에 결과 파일을 읽을 수 있는 권한과 파일을 전달합니다. 결과에는 사용자의 EXIF 선택에 따라 메타데이터가 포함될 수 있습니다.

갤러리 사진의 시스템·클라우드 백업 및 공유 이후의 처리는 해당 서비스의 정책과 사용자의 설정을 따릅니다. 개발자에게 자동 전송하지 않습니다. 외부로 저장·전송한 파일은 해당 위치에서 별도로 관리하고 삭제해 주세요.

7. 권한, 보호와 백업

인터넷·네트워크 상태 접근은 광고 서비스에 사용합니다. 사진 읽기는 시스템 사진 선택기를 사용하고, 결과 저장은 Android MediaStore를 사용합니다. 전체 사진·저장공간, 위치, 연락처, 통화·전화 상태, 카메라 또는 광고 ID 권한을 요청하지 않습니다.

설정·기록·임시 결과는 앱 전용 저장 영역에 보관합니다. 앱은 별도 파일 암호화를 제공하지 않으므로 기기 잠금 등 운영체제의 보호 기능을 이용해 주세요. 앱 설정·기록·내부 결과가 Android 자동 클라우드 백업과 기기 이전에 포함되지 않도록 백업을 비활성화하고 제외 규칙을 적용합니다. 갤러리에 저장한 사진은 이 규칙의 대상이 아닙니다.

8. 삭제 방법과 이용자의 권리

  • 최근 기록: ‘최근 작업 → 최근 기록 삭제’로 삭제합니다. 갤러리 사진과 내부 결과 파일은 이 버튼으로 삭제되지 않습니다.
  • 앱 내부 정보: Android의 ‘설정 → 앱 → Photo Size Fix → 저장공간 → 데이터 삭제’ 또는 앱 제거로 설정·기록·내부 결과를 삭제할 수 있습니다. 메뉴 이름은 기기에 따라 다를 수 있습니다.
  • 저장·공유한 사진: 갤러리, 공유한 앱 또는 백업 서비스에서 직접 삭제합니다.

개발자는 기기의 사진과 기록에 원격으로 접근할 수 없습니다. 적용되는 법령에 따른 열람·정정·삭제·처리 제한 등의 문의는 아래 연락처로 보낼 수 있으며, 광고 서비스 정보는 Google의 요청 절차도 이용할 수 있습니다.

9. 문의, 아동의 개인정보와 변경 안내

이메일 문의 시 사용자가 제공한 이메일 주소와 문의 내용은 답변·후속 대응에 필요한 기간 동안 처리합니다. 문의 목적을 달성하면 불필요한 정보를 삭제하며, 법령상 보관 의무가 있으면 해당 기간을 따릅니다. 문의에 원본 사진, 위치정보 또는 기타 민감한 정보를 불필요하게 첨부하지 마세요.

앱은 성인 사용자를 대상으로 하는 사진 용량 유틸리티이며 아동을 대상으로 설계되지 않았습니다. 아동의 개인정보 처리에 대한 우려가 있으면 아래 연락처로 문의해 주세요. 기능이나 개인정보 처리 방식이 바뀌면 이 페이지와 수정일을 갱신하고, 필요한 경우 앱 내 안내를 제공합니다.
