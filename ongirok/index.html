개인정보처리방침 — 마음장부

시행일 및 최종 수정일: 2026년 10월 23일

YJ Studio (Google Play 개발자명: YJ Lab)가 제공하는 마음장부 / HeartLedger(Android 패키지: com.ongirok.app)의 개인정보 처리에 대해 안내합니다. 광고가 포함된 업데이트(1.2.0 이상, 1.3.0 포함)를 기준으로 작성했습니다. 광고 없는 이전 버전에는 아래 광고 관련 처리가 적용되지 않습니다.

1. 기기에 저장하는 정보와 목적

사용자가 직접 입력한 사람의 이름·별명·관계·소속·메모, 경조사 종류·행사명·날짜·장소·메모, 주고받은 금액·명의·전달자·전달일·방법·완료 여부, 참석 상태·방문일·참석 계획, 보낸/받은 선물의 이름·수량·금 무게·단위·날짜·메모와 앱 설정을 기기 안의 앱 전용 저장 영역에 보관합니다.

이 정보는 경조사 기록·조회·검색·합계 계산·수정·삭제 및 사용자가 요청한 백업·복원을 위해 기기 안에서만 처리합니다. 예시 체험은 가상 데이터이며 개인 기록과 별도 저장 공간을 사용합니다. 개발자는 사용자의 기기 내 기록을 보관하거나 원격으로 열람할 수 없습니다.

2. 광고 서비스와 처리 정보

앱에는 회원가입·로그인, 자체 장부 서버, 별도의 사용 분석 도구 또는 자동 클라우드 동기화 기능이 없습니다. 이름·행사·금액·선물·메모·검색어 등 장부 기록을 개발자 서버나 광고 서비스에 보내지 않습니다. 문장 검색도 기기 안에서 처리하며 기록을 외부 AI 서비스에 보내지 않습니다.

광고 포함 Android 앱은 Google AdMob(GMA Next-Gen SDK)과 Google User Messaging Platform(UMP)을 사용합니다. Google 광고 SDK는 광고 제공·측정, 분석 및 부정 사용 방지를 위해 다음 정보를 수집·공유할 수 있습니다.

광고 SDK가 수집한 정보는 TLS로 암호화해 전송됩니다. Google 측 처리·보유·삭제와 광고 파트너에 관한 사항은 Google 광고 개인정보 안내와 Google 개인정보처리방침을 확인해주세요. 개발자가 Google이 처리하는 광고 정보를 장부 서버에 별도로 보관하지는 않습니다.

3. 광고 개인정보 선택

지원 지역에서는 UMP가 필요한 개인정보 선택 화면을 제공합니다. 변경이 필요한 경우 앱의 설정 → 광고와 개인정보 → 광고 개인정보 설정에서 선택을 다시 열 수 있습니다. 제공되는 선택과 광고 방식은 지역·동의 상태·Google 정책에 따라 달라집니다. 맞춤형 광고 동의를 거부해도 비개인화·제한된 광고를 위한 기본 처리가 발생할 수 있습니다.

광고 선택이나 광고 수신 실패 때문에 장부 기능을 차단하지 않습니다. 광고를 요청할 수 있는 유효한 개인정보 선택 상태를 확인하지 못하면 광고를 요청하지 않습니다. Android 광고 개인정보 설정에서도 광고 ID를 재설정하거나 삭제할 수 있으며, 이 설정이 모든 종류의 광고 데이터 처리를 중단시키는 것은 아닙니다.

4. 사용자가 직접 선택한 백업·가져오기

백업 내보내기는 사용자가 직접 실행하고 Android 시스템 파일 선택창에서 지정한 위치에 JSON 또는 CSV 파일을 저장합니다. 사용자가 외부 클라우드 저장소 등 다른 서비스의 위치를 선택하면 파일이 그 제공업체에 전달될 수 있으며 해당 서비스의 처리방침이 적용됩니다. 개발자에게 백업 파일이 전달되는 것은 아닙니다.

가져오기는 사용자가 선택한 파일을 읽어 미리보기를 표시하고 확인 후 기기에 저장합니다. 전체 연결 관계를 보관·복원하려면 JSON 백업을 사용합니다. 백업 파일은 암호화되지 않으며 인물 정보와 금전 기록을 포함할 수 있으므로 신뢰하는 위치에 보관하고 필요한 범위에서만 공유해주세요.

5. 권한

광고와 개인정보 선택 확인에 인터넷·네트워크 상태 권한을 사용하며 광고 SDK에 광고 ID 권한이 포함됩니다. 장부 작성·검색·조회는 인터넷 없이도 가능합니다. 연락처, 정확한 위치, 카메라, 사진 전체 접근 또는 전체 저장공간 접근 권한을 요청하지 않습니다. 백업·복원은 시스템 파일 선택창에서 사용자가 선택한 파일·위치에 한해 처리합니다.

6. 보유 기간과 삭제

기록과 설정은 사용자가 삭제하거나 앱 데이터를 제거할 때까지 기기에 보관합니다. 경조사 기록을 삭제하면 연결된 금전·참석·선물 기록도 삭제합니다. 전체 기록은 Android의 설정 → 앱 → 마음장부 → 저장공간 → 데이터 삭제 또는 앱 제거로 지울 수 있습니다. 기기에 따라 메뉴 이름은 다를 수 있습니다.

앱 데이터 삭제는 Google이 이미 처리한 광고 정보를 원격 삭제하는 기능이 아닙니다. Google 측 정보의 관리·삭제는 Google의 안내와 설정을 이용해주세요.

개발자 서버에는 기록 사본이 없습니다. 사용자가 따로 내보낸 백업, 다른 앱에 전달한 파일과 클라우드 사본은 앱 데이터 삭제와 별개로 남으므로 해당 위치에서 직접 삭제해야 합니다. 앱 삭제나 기기 변경 전에 필요한 기록은 전체 JSON 백업으로 보관해주세요.

7. 보호 조치와 이용자의 권리

기록은 앱 전용 저장 영역과 운영체제의 앱 접근 제한을 이용해 보관합니다. 앱 자체의 별도 암호화 저장·암호화 백업·앱 잠금 기능은 제공하지 않습니다. 기기 잠금과 운영체제 업데이트, 안전한 백업 보관으로 기록을 보호해주세요.

이용자는 앱에서 기록을 열람·수정·삭제하고 전체 JSON 백업을 내보낼 수 있습니다. 서버 계정이 없으므로 별도의 계정 삭제 절차가 필요하지 않습니다. 적용 법령에 따른 개인정보 관련 열람·정정·삭제·처리 제한 문의는 아래 이메일로 할 수 있습니다. 개발자는 기기 내 기록에 원격 접근할 수 없어 그 기록을 대신 수정하거나 삭제할 수 없습니다.

앱 기록은 Android 자동 클라우드 백업과 자동 기기 이전 대상에서 제외하도록 설정했습니다. 운영체제·기기 제조사의 기능은 해당 제공자의 정책과 설정에 따릅니다.

8. 문의·정책 사이트·아동

이메일 문의를 보내면 사용자가 제공한 이메일 주소와 문의 내용을 답변 및 후속 대응에 필요한 기간 동안 처리합니다. 목적 달성 후 불필요한 정보는 삭제하고 법령상 보관 의무가 있으면 해당 기간을 따릅니다. 문의 시 비밀번호, 금융 계좌 정보, 제삼자의 인물 정보 또는 전체 장부·백업 파일 등 불필요한 민감 정보를 보내지 마세요.

이 정책 웹사이트는 GitHub Pages로 제공됩니다. 웹사이트 접속 정보는 GitHub 개인정보처리방침에 따라 처리될 수 있습니다. 외부 이메일·파일 저장 서비스를 이용하면 해당 서비스의 정책이 적용됩니다.

마음장부는 자신의 경조사를 관리하는 성인을 위한 앱이며 아동을 대상으로 설계하지 않았습니다. 아동 개인정보 관련 우려가 있으면 아래 연락처로 문의해주세요.

9. 변경 안내와 연락처

기능이나 데이터 처리 방식이 바뀌면 이 페이지의 내용과 최종 수정일을 갱신하고 필요한 경우 앱 업데이트나 안내로 알립니다.
