개인정보처리방침 — Easy Magnifier

시행일 및 최종 수정일: 2026년 10월 4일

YJ Studio가 제공하는 Easy Magnifier (Android 패키지: com.yjlab.easymagnifier)의 개인정보 처리에 대해 안내합니다.

1. 사진·카메라·인식 글자

카메라 미리보기는 돋보기, 손전등, 화면 고정에 사용합니다. 사용자가 시스템 사진 선택기로 지정한 사진만 읽고 원본은 수정하지 않습니다. 고정 프레임과 가져온 이미지는 작업 중 메모리에 유지하며 갤러리에 자동 저장하지 않습니다. 한국어·영어 OCR 모델은 앱에 포함되어 사진과 카메라 프레임을 기기에서 인식합니다. 사진·카메라 프레임·인식 글자를 개발자 서버나 광고 요청에 보내지 않습니다. 회원가입이나 자체 앱 서버가 없습니다.

최근 OCR 기록 저장은 기본 꺼짐입니다. 켜면 최대 10개를 저장하고 한도를 넘으면 오래된 항목을 제외합니다. 저장을 끄거나 기록 삭제를 실행하면 저장 기록을 지웁니다. 보기 모드·읽기 속도·기록 선택 등 앱 설정도 기기에 저장합니다.

2. 광고와 외부 서비스

Google Mobile Ads(AdMob)와 User Messaging Platform을 사용합니다. 광고 제공·측정, 분석·진단 및 부정 사용 방지를 위해 기기·광고 식별자, IP 주소와 대략적인 위치, 앱·광고 상호작용, 진단·성능 정보가 처리될 수 있습니다. 범위는 지역·동의·기기·Google 설정에 따라 달라집니다. 앱의 충전 기록, 사진과 인식 글자를 광고 요청에 넣지 않습니다. 현재 테스트 빌드는 Google 테스트 광고 ID를 사용합니다.

광고 SDK 통신은 전송 중 암호화되며 국외에서 처리될 수 있습니다. 제공자의 보관·삭제 기준은 해당 정책을 따릅니다. 광고 요청은 Google의 광고 요청 가능 상태를 확인한 뒤에만 시작합니다. 필요한 경우 앱 설정의 ‘광고 개인정보 선택’에서 선택을 바꿀 수 있습니다. Android 설정에서 광고 ID를 재설정하거나 삭제할 수 있으나 모든 진단·네트워크 처리가 중단되는 것은 아닙니다.

  • Google 개인정보처리방침
  • Google 광고 안내
  • 광고 SDK 데이터 공개 안내

외부 링크를 열면 브라우저와 해당 사이트의 정책이 적용됩니다. 이 정책 사이트의 접속 정보는 GitHub 개인정보처리방침에 따라 처리될 수 있습니다.

3. OCR 진단 정보·음성 읽기·복사

Google ML Kit는 글자 인식과 별개로 기기·앱 정보, 설치 단위 식별자와 기능 사용·성능·오류 관련 진단 정보를 분석 목적으로 처리할 수 있습니다. 이 통신은 HTTPS로 암호화됩니다. 사진·인식 글자의 내용을 업로드하는 OCR 서비스는 사용하지 않습니다. 자세한 범위는 ML Kit 데이터 공개 안내와 Google 정책을 확인하세요.

‘소리로 읽기’를 누르면 인식 글자를 설치된 Android TTS 엔진에 전달합니다. 엔진·음성에 따라 네트워크를 이용할 수 있으며 해당 제공자의 정책이 적용됩니다. 오프라인 음성을 선택하고 언어 데이터를 설치하면 해당 음성의 기기 내 처리를 이용할 수 있습니다. 앱 제거가 TTS 제공자의 별도 데이터를 삭제하지는 않습니다. ‘복사’는 시스템 클립보드에 글자를 넣으므로 붙여넣는 앱과 운영체제 설정에 따라 다른 앱이 이를 사용할 수 있습니다.

4. 권한

  • 카메라: 실시간 돋보기·손전등·프레임 고정에 사용합니다.
  • 인터넷·네트워크·광고 ID: 광고·동의 및 SDK 진단 통신에 사용합니다.

광범위한 사진·저장공간 권한, 마이크·위치·연락처 권한은 요청하지 않습니다. 가져오기는 사용자가 선택한 사진에만 접근하는 시스템 기능을 이용합니다.

5. 보관·보호·삭제

설정과 선택한 기록은 앱 전용 기기 저장 영역에 보관합니다. 앱 자체가 별도로 암호화하는 기능은 없으므로 기기 잠금 등 운영체제의 보호 기능을 이용해 주세요. Android 클라우드 백업과 자동 기기 이전 대상에서 앱의 저장 데이터를 제외하도록 설정했습니다. 운영체제·제조사가 제공하는 기능에는 해당 제공자의 정책이 적용됩니다.

앱의 기록 삭제 기능, Android ‘설정 → 앱 → 해당 앱 → 저장공간 → 데이터 삭제’ 또는 앱 제거로 로컬 데이터를 삭제할 수 있습니다. 기기 메뉴 이름은 다를 수 있습니다. 앱의 로컬 기록 삭제가 Google 광고·진단 데이터나 외부 서비스의 정보를 삭제하는 것은 아닙니다. 개발자는 기기 내 데이터에 원격으로 접근할 수 없습니다. 외부 제공자의 데이터 관련 요청은 해당 제공자 절차도 이용해 주세요.

6. 문의와 이용자의 권리

이메일 문의 시 제공한 이메일 주소·문의 내용을 답변과 후속 대응에 필요한 기간 동안 처리합니다. 목적 달성 후 불필요한 정보는 삭제하며 법령상 보관 의무가 있으면 해당 기간을 따릅니다. 주민등록번호, 비밀번호, 금융 정보나 사적인 사진·문서를 보내지 마세요. 적용되는 법령에 따른 열람·정정·삭제·처리 제한 관련 문의도 아래 이메일로 할 수 있습니다.

앱은 만 13세 미만 아동을 대상으로 설계하지 않았으며 회원가입이나 아동 개인정보 입력을 요구하지 않습니다. 아동 개인정보 관련 우려가 있으면 연락해 주세요.

7. 변경과 연락처

기능이나 처리 방식이 바뀌면 이 페이지의 내용과 최종 수정일을 갱신하고 필요한 경우 앱 업데이트나 안내로 알립니다.
